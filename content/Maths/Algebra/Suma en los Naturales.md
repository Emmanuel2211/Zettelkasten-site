# Suma en los $\mathbb{N}$

> [!theorem] **Definición.** (Suma $+_{\mathbb{N}}$)
>
> $$
> +_{\mathbb{N}} : \mathbb{N} \times \mathbb{N} \to \mathbb{N}
> $$
> operación binaria tal que
> 1. $0 + n = n \quad \forall n \in \mathbb{N}$ 
> 2. $s(m) + n = s(m+n) \quad \forall m,n \in \mathbb{N}$

> [!theorem] **Teorema.** (Propiedades de $+_{\mathbb{N}}$)
>
> Para cualesquiera $m,n,p \in \mathbb{N}$ se cumple:
> - $m +(n+p) = (m+n)+p$
> - $m + n = n+m$
> - $m+p = n+p \iff m=n$
> - $m\leq n \iff \exists k \in \mathbb{N} \ \ \text{ tal que } \ \ m + k= n$
> - $m \leq n \iff m+ p \leq n+p$
> - $m + n = 0 \iff m = 0 \land n = 0$
