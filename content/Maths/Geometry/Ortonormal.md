- Una lista de vectores en llamada *ortonormal* si para cada vector en la lista tiene **norma 1** y **es ortogonal** a todos los demás vectores en la lista.
Es decir, una lista $e_{1},\dots,e_{m}$ de vectores en $V$ es ortonormal si
$$
\langle e_{j},e_{k} \rangle = \begin{cases}
1 \ \ \ \ \text{ if } j = k, \\[0.5em]
0 \ \ \ \ \text{ if } j \neq k
\end{cases}
$$
para todo $j,k \in \{ 1,\dots,m \}$
